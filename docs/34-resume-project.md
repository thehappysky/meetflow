**MeetFlow 销售会谈多智能体协作系统｜AI 应用开发**

**技术栈：** Python、FastAPI、LangGraph、Pydantic、SQLAlchemy、SQLite、Whisper

面向企业软件销售，实现录音转写、可追溯纪要、待办及周报，并为主管提供独立质检。

1. 针对改期与条件错绑，设计多 Agent 证据交接与独立审查，结合原文回填、日期归一和有限返工，实现纪要与待办可追溯。
2. 针对中断与重复执行，设计任务租约、写入校验及检查点代次隔离，持久化消息与产物；通过进程强杀测试，验证接管后复用已保存响应。
3. 针对并发读取阻塞，改用关联查询并复用事务连接；本机 100 个账号、300 次并发读取全部成功且范围正确，P95 约 0.68 秒。

## 用户提供简历示例后的改进原则

2026-11-13用户提供具身陪伴Agent与编程Agent项目截图，要求学习设计和写法。可借鉴的是以明确问题组织技术点，把内部机制写出来：例如上下文与持久记忆分层、身份校验前置于检索、只读工具并行而写入串行、将后台维护任务移出实时交互链路。不能将示例的实现或数字移植为本项目经历。

本项目后续三条优先围绕：证据契约与Agent交接机制、持久任务及中断恢复、权限/中心版本及真实数据链路；每条都应回答“什么问题—怎么实现—怎样验证”。四个角色的数量、框架名和工具上限本身不构成效果。性能数字必须附场景、分母及计量范围，不能把元数据读取P95写成音频处理时延。简历正文继续最多三点，每点尽量两行；复杂机制与失败边界放面试说明。
