## 实现范围

此前三角色原型仅演示交互。本轮增加真实登录、团队绑定的一次性邀请码、销售个人区、确认上报的中心快照，以及销售申请／负责主管确认的中心更正。默认网页改为真实账号工作区。

新增 access_*、workspace_* 数据表，旧会议、录音、质检资料不重置。旧资料没有账号归属，默认账号模式隔离旧 `/api/projects`、`/api/meetings`、`/api/sales` 等接口；原模块源码保留，尚未完成质检的账号迁移。

## 本机使用

地址：<http://127.0.0.1:8765>。在仓库目录执行 `.\scripts\start.ps1 -SkipInstall`；首次检出执行 `.\scripts\start.ps1` 安装依赖并构建。

首次创建合成测试公司：依赖安装后，在另一个终端执行 `.\.venv\Scripts\python.exe scripts/bootstrap_access_demo.py`。脚本创建独立测试公司、两个团队、管理员、老板和两位主管；再次执行不重置密码。销售在网页使用邀请码注册。

## 操作路径

1. 管理员选择团队生成销售邀请。打开链接先核对固定公司／团队，再填姓名、账号和密码；不能自选角色或换团队。一人一码，默认 7 天，可撤销。
2. 销售上传录音或粘贴转写；标题、客户、实际日期可空。自动保存并后台整理，未配置真实模型时明确显示规则纪要。
3. 未填标题按北京时间上传时段命名。上传时间和会谈日期分开；未知日期不以上传时间代替。
4. 个人详情查看纪要、后续事项、原文和可选录音；修改只影响个人副本。
5. 上报前填写客户／商机并确认范围，固定本次快照。当前客户是必填文本，尚未接客户库下拉选择和去重。
6. 主管看本团队中心，老板看全公司，销售仅看本人。管理者不能读取未上报个人资料。
7. 销售申请更正，负责主管确认后生成新版并保留旧版；个人删改不影响中心。当前更正支持名称、客户和实际日期，尚不支持纪要正文更正。

## 实际验证

使用用户本地 Chrome 打开 7 个真实账号标签页，未使用内置浏览器或原型角色切换。

| 场景 | 浏览器实测结果 |
|---|---|
| 两组邀请注册加入 | 通过；固定指定团队和销售角色 |
| 已使用、撤销、无效邀请 | 拒绝继续注册 |
| 重复账号后重试 | 先拒绝重复账号，原邀请仍可注册新账号 |
| 未上报个人会谈 | 老板和两组主管中心均不可见 |
| 两场分别上报 | 一组主管 1 场，二组主管 1 场，老板 2 场 |
| 同团队另一销售 | 看不到同事个人记录和上报 |
| 销售更正、负责主管确认 | v1→v2，保留 v1；另一团队没有该申请 |
| 个人改名和移除 | 中心 v2 和旧版保持 |
| 错误密码／退出 | 错误密码被拒绝；退出一页不影响其他账号 |
| 中心导出 | 主管成功下载 Markdown，内容包含纪要和原文 |

后端全量 **54 项测试通过**（本轮新增 12 项），Ruff 与前端类型／生产构建通过。后端另外验证未登录、伪造令牌、跨公司／团队直接访问详情／搜索／导出／音频／更正审核、账号停用、过期会话、邀请码抢注仅一人成功、注册注入角色／团队被拒绝、提交幂等及版本冲突。隐藏按钮不能替代服务器鉴权。

真实音频补测：二组销售经认证 HTTP 上传既有 AliMeeting 58.875 秒公开样本，本地 faster-whisper small CUDA 转写产生 29 条证据。网页音频 readyState=4、时长 58.875 秒、无媒体错误。个人音频本人 200，主管／老板 404。样本标记非销售资料，未上报；纪要仍为规则模式，不是模型语义效果测试。结果在忽略的 `test-results/access-browser/real-audio.json`。

浏览器选文件受 ChatGPT 扩展“允许访问文件网址”限制，未完成浏览器选文件上传实操，未修改扩展设置。真实上传补测走认证 HTTP，不冒充浏览器上传通过。最终截图保存时，控制工具无法可靠确认 Windows 当前浏览器网址而停止；截图未生成，7 个标签页最终保留状态无法再次核验。注册、上报、更正、隔离等步骤已实际观察结果。

## 实测修复与限制

- 更正列表切换导航重新取数，增加刷新入口，空闲约 10 秒更新列表。
- 换邀请链接监听地址变化；输入新码清空旧团队预览，避免显示旧码信息。
- 上传／上报统一显示北京时间，实际会议日期独立。
- 已上报详情改显示查看中心入口，失败重试复用提交标识。
- 审核列表“修改前”使用对应旧版本，避免随中心新版变化。

Word／PDF 简报周报、客户进展首页、承诺提醒、质检和新权限的一体化尚未完成。中心撤下、账号停用／创建主管已有服务器接口和权限测试，尚未全部提供管理页面。中心为软撤下，不永久删除文件，恢复页面和保留策略待开发；成员转组未实现。

本版仍是本地单进程 SQLite，未做公网、集群、规模并发或真实模型效果验收。登录失败限流为单进程内存，无密码找回、SSO 或正式企业初始化流程。旧浏览器脚本仅在隔离 legacy 测试服务回归，CI 显式关闭该独立测试服务认证，不改变默认账号模式。

主要文件：`auth.py` 负责账号／邀请；`workspace.py` 负责归属／中心证据／更正；`WorkspaceApp.vue` 为真实工作区；`test_access.py` 为行为测试；`bootstrap_access_demo.py` 为本地测试初始化。
