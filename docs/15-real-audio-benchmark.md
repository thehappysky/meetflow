# 首轮真实录音下载与抽测报告

## 结论与证据范围

已完成官方 AliMeeting Eval 包下载和真实本地 ASR 抽测。8 场远场录音实际合计约 4.205 小时，固定抽取前/中/后各一段，共 24 段、1461.89 秒（24.36 分钟）。24 段通过上传、实际转写、时间戳、证据引用、音频范围读取和 Markdown 导出检查。

这证明当前文件链路能运行，不等于语义质量达标。ASR 使用真实 Whisper small；纪要和 Agent 仍使用明确标记的规则提供者，没有配置真实 LLM。普通研究会议不是销售客户录音，不能据此宣称销售需求、异议或承诺识别的业务准确率。没有自动分离说话人，音频转写片段仍标为未知说话人。

- faster-whisper 1.2.1、CTranslate2 4.9.0、PyAV 16.1.0、praatio 6.2.2；完整可选依赖复现清单见 `requirements-audio.lock`。

## 抽样和计分方法

1. 按会议文件名排序，每场以录音总时长的 5%、45%、80% 为目标选开始位置，选附近全体说话人都停顿的边界。
2. 以约 60 秒为目标选结束边界，避免截断人工标注话语；实际片段为 30.0—150.4 秒，因此不是严格每段一分钟。抽样不根据 ASR 好坏挑选。
3. 从八通道 WAV 固定取第 0 通道，保存单通道 PCM16；没有波束成形或语音分离。参考区间必须完整包含在片段里。
4. 参考文字按人工标注起始时间排序串接；识别文字按输出顺序串接。两者做 NFKC、转小写、去标点空白，仅保留字母/数字，再计算 Levenshtein 编辑距离。
5. 字符错误率 `CER = 编辑距离 / 参考字符数`；汇总先加编辑距离与参考字数再相除，不取各段百分比的简单平均。不做繁简或中文数字/阿拉伯数字统一。

所有 24 段都有标注上的重叠发言。单路输出和重叠参考的排序不唯一，数字与口头语写法也影响结果，因此下面是**诊断用粗略 CER，不是官方 M2MeT 多说话人评分，也不是销售纪要准确率**。不能用 `1-CER` 宣称整体理解准确率。

## 测试发现与已修复问题

### 1. PyAV 解码 API 不兼容

初次安装解析到 PyAV 19.0.2，faster-whisper 1.2.1 调用 `av.open(metadata_errors=...)` 报错，首轮 24 段全部未进入识别。失败历史和应用记录保留，不能把其空输出 CER=1.0 当成真实识别错误率。

已在 audio 可选依赖中固定实际验证的 faster-whisper 1.2.1、PyAV 16.1.0，增加真实 WAV 解码回归测试。此测试不下载模型、没有替换解码器；未安装可选音频依赖时明确跳过。批量脚本后续遇到分析失败会保存结果并停止，避免重复消耗整批。

### 2. 直接打开报告链接时项目显示错误

录音结果深链接原先可能显示首个项目名称。已让读取报告后同步其实际 project_id，补充浏览器回归断言；本地 Chrome 刷新真实报告后已验证项目选择器正确。

## 怎样复现

在仓库根目录，先按锁文件安装环境和本地应用：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-audio.lock
.\.venv\Scripts\python.exe -m pip install --no-deps -e .
.\.venv\Scripts\python.exe scripts/prepare_audio_benchmark.py
.\.venv\Scripts\python.exe scripts/run_audio_benchmark.py prepare
```

配置 `.env` 的 ASR 路径为下载后的模型目录，选择本机可用设备，启动服务后：

```powershell
.\.venv\Scripts\python.exe scripts/run_audio_benchmark.py run
```

脚本会跳过 results.json 中已通过的片段。要做新的实验，先将现有 results.json 保存为新的历史文件名；不要删除原记录或改写旧结果冒充新实验。模型更换后还需重启应用，原本模型缓存才会释放。

数据和模型下载带断点续传、状态/长度检查、SHA256 清单；解包只允许普通目标文件，拒绝越界路径和链接。不要把脚本换成下载后直接执行第三方文件。

当前应优先提升中文远场/重叠转写质量，尝试更强中文 ASR、语音前端或通道策略，并用同一固定样本对照；补充近场或无重叠控制样本，采用更严格的标准评分。此后接入真实 LLM，独立评估需求、承诺、负责人和行动项。真实销售会谈还需要授权和人工业务标注。
