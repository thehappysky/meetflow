# 日常操作交互原型

- `meetflow-daily-workflow.html`：独立预览，浏览器打开或用静态服务器访问。
- `meetflow-daily-workflow.fragment.html`：对话内预览的可编辑源片段。

所有记录、客户、人物、时间和内容均为合成示例。它不连接 FastAPI、数据库或模型，不读取/上传录音内容，不生成真实 Word/PDF，也不提供真实账号权限。顶部身份选择仅供体验不同角色。

## 如何体验

1. 销售首页点击“用示例录音体验上传”，观察无需表单且结果自动保存。文件选择/拖入只模拟进入列表，随后展示的是固定示例内容。
2. “工作简报”可编辑正文、补日期或保留时间待确认；确认后查看 Word/PDF 的相同内容版式预览。
3. 选中未上报录音并“上报所选”；原型暂按上报时补客户归属展示，此规则已询问用户、尚待确认。
4. “已上报”打开记录，申请更正标题/日期并填原因；顶部切主管，处理更正申请，中心生成 v2 并保留旧版。
5. 切回销售删除个人录音；“已上报”的中心版本仍存在；老板中心只汇总已上报资料。
6. “重新体验完整流程”还原示例。状态主要在当前页面内，刷新不保证保留整套示例操作，不是产品的持久恢复实现。

## 已验证

本地 Chrome：示例上传、周报确认、Word/PDF 预览、上报、销售更正申请、主管新版、个人删除保留中心、老板范围均已实际点选。320px 下检查报告/主管/老板无横向溢出，390px 首页检查通过；浏览器未捕获脚本错误。临时视口已恢复。

原型重点是主要操作路径；独立质检完整页面、真实账号管理、所有异常及版本历史查看界面尚未完整展示。
